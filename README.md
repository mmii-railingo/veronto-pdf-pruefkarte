# PDF-Prüfkarte für die Weitergabe

Eine statische, interaktive Arbeitshilfe für die Prüfung einer fertigen PDF-Versandfassung.

Die neun Schritte behandeln Versandfassung, Sichtprüfung, Such- und Kopiertest sowie Dateiname, Empfänger und Freigabe. Die Häkchen und der Fortschritt werden im gerade geöffneten Browser angezeigt. Über die Druckfunktion lässt sich die ausgefüllte Karte in den eigenen Vorgang übernehmen.

Öffentliche Prüfkarte: https://mmii-railingo.github.io/veronto-pdf-pruefkarte/

Die Seite besteht aus einer HTML-Datei mit CSS und einem kleinen Skript für die Häkchenzählung. Sie benötigt keinen Build und lässt sich durch Öffnen der Datei ansehen.

Eine Arbeitshilfe von Martin Meng, veronto GmbH & Co. KG, Wiesbaden.

Weitere Informationen und das PDF-Schwärzungswerkzeug: https://veronto.de/pdf-schwaerzen
